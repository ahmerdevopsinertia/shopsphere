Prisma Schema Addition

Add:

model Cart {

  id String @id @default(uuid())

  userId String @unique

  user User @relation(
    fields: [userId],
    references: [id],
    onDelete: Cascade
  )

  items CartItem[]

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}


model CartItem {

  id String @id @default(uuid())

  cartId String

  productId String

  quantity Int

  cart Cart @relation(
    fields: [cartId],
    references: [id],
    onDelete: Cascade
  )

  product Product @relation(
    fields: [productId],
    references: [id],
    onDelete: Restrict
  )

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@unique([cartId, productId])
}
Why @@unique([cartId, productId])?

Important business rule:

🚀 Sprint 6 — Session 2
POST /cart/items

This API will add a product to the authenticated user's cart.

Step 1 — Business Rules

The service should implement these validations in order:

User authenticated
        ↓
Product exists
        ↓
Product is ACTIVE
        ↓
Quantity > 0 (DTO validation)
        ↓
Find/Create Cart
        ↓
Item already exists?
        ↓
Yes → Increase quantity
No  → Create new CartItem
        ↓
Return updated cart

Notice that we are not reserving inventory here. Inventory is only reserved during Order Creation (Sprint 5). The cart simply records customer intent.

Step 2 — Repository Methods

Let's start by implementing these repository methods.

Cart Repository

    },

Step 6 — Return Response

At the end of the service, don't return just the created/updated item.

Instead, reload the cart:

const updatedCart =
    await this.cartRepository.findByUserId(
        user.sub,
    );

and map it to your CartResponseDto.

This gives the frontend the complete current cart after every change, which simplifies client-side state management.

API Response

I recommend structuring the response like this:

{
  "id": "cart-id",
  "items": [
    {
      "productId": "product-id",
      "name": "iPhone 16 Case",
      "price": 39,
      "quantity": 2,
      "subtotal": 78
    }
  ],
  "total": 78
}

This keeps the response useful while avoiding another immediate GET /cart request.

Testing Checklist

When you've implemented this, verify these scenarios:

✅ First product added → Cart is automatically created.
✅ Add another different product → New CartItem is created.
✅ Add the same product again → Quantity increases instead of creating a duplicate row.
✅ Invalid product ID → 404 Product not found.
✅ Inactive product → 400 Product is not active.
✅ Invalid quantity → DTO validation returns 400.

Once this API is working, we'll move on to GET /cart, which will reuse most of the response mapping logic you've already built.

🚀 New API
PUT /cart/items
Purpose

Replace the entire contents of the user's cart with the items provided in the request.

This means:

✅ Update existing items
✅ Add new items
✅ Remove items not present in the request

async replaceItems(
    cartId: string,
    existingItems: any[],
    incomingItems: CartItemsDto[],
) {
    return this.prisma.$transaction(async (tx) => {

        // Delete removed items

        for (const existing of existingItems) {

            const stillExists = incomingItems.find(
                item => item.productId === existing.productId,
            );

            if (!stillExists) {

                await tx.cartItem.delete({
                    where: {
                        id: existing.id,
                    },
                });

            }
        }


        // Update existing / Create new

        for (const incoming of incomingItems) {

            const existing = existingItems.find(
                item => item.productId === incoming.productId,
            );

            if (existing) {

                await tx.cartItem.update({
                    where: {
                        id: existing.id,
                    },
                    data: {
                        quantity: incoming.quantity,
                    },
                });

            } else {

                await tx.cartItem.create({
                    data: {
                        cartId,
                        productId: incoming.productId,
                        quantity: incoming.quantity,
                    },
                });

            }
        }

    });
}
Step 6 — Reload cart
const updatedCart =
    await this.cartRepository.findByUserId(user.sub);

return this.toCartResponse(updatedCart!);
